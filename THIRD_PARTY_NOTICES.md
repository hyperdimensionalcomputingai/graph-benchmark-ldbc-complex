# Third-party provenance and notices

Inventory prepared on 2026-10-24 for the migration of the local `../ldbc-suite-test` workspace. That source has no Git commits, so its exact original upstream query revision and contributor history cannot be established from Git. This inventory describes the material copied here, not the sibling repository's custom 30-query suite.
